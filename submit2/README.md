## 核心结论

- 每天 11:00（北京时间）自动运行，也可在窗口内手动运行
- 数据源：东方财富概念板块 `BK0809`（AI智能体），共 151 只成分股
- 综合分 = 成交额 40% + 涨跌幅 30% + 资金净流入 20% + 新闻提及 10%（板块内百分位）
- 取 Top10，生成 49 字以内摘要 + 当日关键新闻链接
- 推送：企业微信、飞书、钉钉、Telegram、邮件，可逐渠道启停
