# 部署说明

## 1. 交付物结构

```text
test2/
├── app.py                 # 桌面窗口主程序
├── run.bat                # 双击启动脚本
├── build_exe.bat          # PyInstaller 打包脚本
├── dist/test2.exe         # 已打包可执行文件（免 Python）
├── core/                  # 抓取、评分、报告、推送、调度核心代码
│   ├── eastmoney.py
│   ├── scoring.py
│   ├── report.py
│   ├── push.py
│   ├── scheduler.py
│   └── workflow.py / workflow_cli.py
├── tests/test_core.py     # 单元测试
└── reports/               # 运行后自动生成报告
```

## 2. 快速启动

### 方式一：直接运行 exe（推荐）

1. 双击 `test2\dist\test2.exe`。
2. 窗口打开后点“立即运行”即可抓取并生成当天 Top10。
3. 首次保存设置时会在 exe 同级生成 `config.json`。

### 方式二：源码运行

```bash
cd "C:\Users\钱铃\Desktop\ai test\test2"
py -3 app.py
```

也可以双击 `run.bat`，脚本会优先启动 `dist\test2.exe`，否则用 `pythonw` 打开源码版。

## 3. 推送配置

1. 窗口点击“推送设置”。
2. 在“推送渠道”页勾选要启用的渠道：
   - 企业微信：填写机器人 Webhook 地址
   - 飞书：填写自定义机器人 Webhook 地址
   - 钉钉：填写自定义机器人 Webhook 地址（安全设置如需加签，请在机器人地址后保留 `secret` 参数，当前版本按地址直发）
   - Telegram：填写 Bot Token 和 Chat ID
   - 邮件：SMTP 服务器、端口、账号、授权码、发件/收件地址
3. 点击“测试已启用渠道”验证连通性，确认无误后点“保存”。

配置保存在 `config.json`，请勿提交到仓库（已在 `.gitignore` 中排除）。

## 4. 定时任务

### 方式一：窗口内定时

打开 exe 后点击“启动定时”，默认每天 11:00（北京时间）自动运行。窗口关闭后定时停止。

### 方式二：Windows 任务计划程序（关窗也可运行）

```bat
schtasks /create /tn "AIAgentHeat" /tr "py -3 \"C:\Users\钱铃\Desktop\ai test\test2\core\workflow_cli.py\"" /sc daily /st 11:00 /f
```

或在“任务计划程序”图形界面中创建每日任务，操作填：

```text
程序：py
参数：-3 "C:\Users\钱铃\Desktop\ai test\test2\core\workflow_cli.py"
开始于：C:\Users\钱铃\Desktop\ai test\test2
```

`workflow_cli.py` 是纯命令行入口，会读取 `config.json` 执行完整流程并输出报告。

## 5. 修改数据源与权重

- 板块：窗口“基础设置”中修改板块代码和名称，默认 `BK0809`（AI智能体）
- 权重：窗口“评分权重”中调整，默认 40 / 30 / 20 / 10，会自动归一化
- 新闻统计：可修改“新闻抓取条数”“统计天数”“新闻链接数”

## 6. 打包 exe

```bash
cd "C:\Users\钱铃\Desktop\ai test\test2"
py -3 -m pip install pyinstaller
build_exe.bat
```

生成物：`test2\dist\test2.exe`。
